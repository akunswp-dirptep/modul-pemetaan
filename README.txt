PENILAIAN TANAH (SIPENTA) - CATATAN RILIS
Versi: 6.4
==================================================

Pembaruan pada versi 6.4 berfokus pada peningkatan fleksibilitas sistem, optimalisasi alur kerja Nilai Bidang Tanah (NBT) & Zona Nilai Tanah (ZNT), serta perbaikan pada antarmuka dan integrasi aplikasi.


[ FITUR BARU ]
1. Upload Revisi ke Sipenta: Menambahkan dukungan untuk mengunggah berkas revisi secara langsung ke dalam sistem Sipenta.
2. Data Pembanding Persil NBT: Pengguna kini dapat melihat dan menganalisis data pembanding secara langsung untuk keperluan Persil Nilai Bidang Tanah (NBT).


[ PENYESUAIAN & PENINGKATAN ]
1. Unduhan Pembaruan Otomatis: Fitur "Cek Pembaruan" telah ditingkatkan. Aplikasi kini akan langsung mengunduh installer (file instalasi) versi terbaru apabila pembaruan tersedia.
2. Optimalisasi Modul NBT: Berbagai penyesuaian fungsionalitas pada fitur Nilai Bidang Tanah (NBT) untuk performa yang lebih baik.
3. Pembaruan Hak Akses Titik Sampel: Pengambilan titik sampel kini menjadi lebih fleksibel dan dapat dilakukan oleh seluruh pengguna yang memiliki hak akses terhadap berkas tersebut.
4. Validasi Workspace: Menambahkan peringatan dan pesan error yang lebih informatif apabila direktori workspace dipindahkan atau tidak ditemukan.


[ PENYESUAIAN LAINNYA ]
1. Layout ZNT: Penambahan layout baru yang dikhususkan untuk mempermudah proses Pembuatan dan Pembaruan Zona Nilai Tanah (ZNT).


[ PERBAIKAN BUG ]
1. Stabilitas API: Perbaikan bug pada integrasi API untuk mencegah kegagalan pertukaran data dan meningkatkan stabilitas sistem secara keseluruhan.
