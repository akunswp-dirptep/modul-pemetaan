========================================================================
README & RELEASE NOTES - PENILAIAN TANAH VERSION 6.2
========================================================================

Aplikasi : Penilaian Tanah
Versi    : 6.2
Tanggal  : Juli 2026

------------------------------------------------------------------------
DESKRIPSI
------------------------------------------------------------------------
Pembaruan pada Penilaian Tanah versi 6.2 membawa sejumlah pengembangan 
fitur baru, optimalisasi integrasi dengan Sipenta, serta berbagai 
penyesuaian antarmuka untuk meningkatkan kenyamanan dan kelancaran 
kerja pengguna.

------------------------------------------------------------------------
DAFTAR PERUBAHAN & PEMBARUAN (RELEASE NOTES)
------------------------------------------------------------------------

[1] PENGEMBANGAN FITUR BARU
* Perhitungan Harga Menyebar: Penambahan modul perhitungan harga menyebar
  yang dikhususkan pada proses Pembaruan NBT (Nilai Bidang Tanah).
* Integrasi Penuh Workspace Sipenta:
  - Menambahkan fitur "Save Workspace" untuk menyimpan area kerja 
    langsung ke Sipenta.
  - Menambahkan fitur "Unduh Workspace" untuk menarik area kerja dari 
    Sipenta ke dalam aplikasi.

[2] PENINGKATAN & PENYESUAIAN FITUR
* Pembaruan NBT & ZNT:
  - Melakukan penyesuaian dan optimalisasi pada fitur NBT secara umum.
  - Menambahkan variasi simbologi baru pada fitur NBT.
  - Menyesuaikan penamaan pada proses Upload Hasil Pengolahan di menu 
    Pembuatan ZNT (Zona Nilai Tanah) agar lebih deskriptif.
* Manajemen Pemetaan & Data:
  - Menambahkan opsi Peta Dasar (Basemap) untuk mempermudah pemilihan 
    citra secara online.
  - Menampilkan tools khusus untuk mengunduh data yang sebelumnya 
    telah diunggah dari Sipenta.
* Optimalisasi Ekspor:
  - Mengubah nama "Tools Ekspor Geodatabase" menjadi "Ekspor Workspace" 
    agar lebih relevan dengan fungsinya.
  - Menambahkan Path Default pada menu Ekspor Workspace untuk 
    mempercepat proses penyimpanan data.

[3] PENINGKATAN PENGALAMAN PENGGUNA (UI/UX)
* Pencegahan Kendala Upload: Menambahkan teks penjelasan/informasi yang 
  lebih detail pada parameter-parameter upload. Hal ini bertujuan untuk 
  memandu pengguna dan meminimalisir kebingungan apabila terjadi 
  error pada sistem.
* Optimasi Tata Letak Tool Palette: Memosisikan ulang tombol "Save" dan 
  "Delete" pada Tool Palette. Penyesuaian jarak ini dilakukan untuk 
  menghindari risiko salah klik (missclick) yang tidak disengaja saat 
  pengguna sedang bekerja.

------------------------------------------------------------------------
KETERANGAN TAMBAHAN
------------------------------------------------------------------------
- Pastikan koneksi internet stabil saat menggunakan fitur integrasi Sipenta
  dan pemilihan Citra Online (Basemap).
- Jika mengalami kendala saat melakukan upload data, harap baca petunjuk
  penjelasan pada parameter untuk mengidentifikasi jenis kesalahan (error).
